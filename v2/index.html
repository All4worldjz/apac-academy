为什么这样排

同一个问题「AI 怎样进入企业」，五家创业公司给出四种答案：交付成品、连接上下文、编排应用、管理数据；Palantir 用二十多年证明了全栈加驻场工程的路径。按顺序读，可以比较价值在哪一层沉淀、竞争在哪一层最激烈。

  1. Genspark：最容易上手，先建立对 Agent 的直觉
  2. Manus：看 Agent 的「电脑」：沙箱与上下文工程
  3. Glean：看 Work AI 的 2B 生意怎么做
  4. Dify：内容最完整的一座学院
  5. Zilliz：回到数据层，理解检索与成本
  6. Palantir：最后看全栈参照与 FDE 方法

03 · Route

巡航路径：出发、学习、返回

每座学院走同一条航线，任何一站都能一键回到这里，或直达下一站。

  1. ◆情报总览

    先看六家公司的横向对照，确定要深入哪一家

  2. 1学习

    按顺序读各模块，第一个模块末尾有影像与声音

  3. 2原典

    在原典阅读室核对来源，标记已读

  4. 3测评

    选一个视角题包，每题标注把握程度

  5. 4报告

    看对齐指数、偏差画像和该补读的材料

  6. ↻下一站

    用页面底部的巡航条进入下一站，或回到导航页

巡航条每个页面底部都有一条巡航条：主页、上一站、七个站点、下一站。电脑上也可以用 Alt + ← / →。
直达任意一站点巡航条上的站点编号；读过的站点会亮起，各学院进度互不影响。
回到原处导航页记住你最后停留的学院和栏目，点「继续」直接回去。
