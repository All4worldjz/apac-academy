08 · Toolkit

实用工具

可以直接拿去用的清单。它们来自四座学院的研究，按使用场景整理。

选型：先判断你要买的是哪一层企业买方

四家公司解决的是不同层的问题，先定层，再比厂商。

  • 员工要直接产出成品（报告、演示、表格）：看 Agent 工作空间类，例如 Genspark
  • 要跨系统、按权限找到公司知识：看企业 Work AI 类，例如 Glean
  • 要自建、可私有化的 AI 应用与流程：看应用开发平台类，例如 Dify
  • 要自建检索与 RAG 底座：看向量数据库类，例如 Zilliz

选型：五个必问问题企业买方

适用于以上任何一类。

  1. 数据存放在哪个区域，能否选择本地或客户自有云
  2. 权限是否沿用原系统，答案能否追溯到来源
  3. 能否选择或更换模型，模型费用怎样计入账单
  4. 成本怎样预测：席位、用量还是两者混合
  5. 退出成本：数据、流程与配置能否导出

尽调：值得向四家公司追问的问题合作与投资

  • Genspark：企业席位收入占比；企业客户的续约与扩张；日韩之外的亚太由谁覆盖
  • Glean：用量计价占收入比例；净收入留存；微软重度客户的赢单率
  • Dify：社区版到企业版的转化路径；伙伴贡献的收入占比；中国区与全球产品的关系
  • Zilliz：前十大客户收入占比；现金跑道与下一轮计划；中国区的私有化政策

给国内云厂商与集成商的五个合作样板渠道与生态

都来自公开案例，可以作为设计合作模式时的参照。

  • 云托管 + 原厂许可：阿里云 DMS 托管 Dify 企业版，许可证向 Dify 单独购买
  • 托管服务进入本地云：Zilliz Cloud 在阿里云杭州、北京、深圳提供服务，可在云市场订阅
  • 集成商补齐本地连接器：丸红 IT Solutions 为日本 SaaS 开发 Glean 自定义连接器
  • 伙伴承担 SLA：Dify 伙伴计划由伙伴提供企业版服务与 SLA
  • 前线部署团队：Genspark 日本团队设有前线部署职能，负责企业落地
