三分钟入门

Primer · 给第一次接触 Dify 的你

Dify 是什么 产品

一个开源的 AI 应用开发平台——用张路宇的话说，是夹在大模型与真实业务之间的「中间层」。不会写代码也能在画布上拖出聊天机器人、知识库问答和自动化流程（Workflow）；会写代码，可以编排数百个节点、接入企业内部系统。模型可以热插拔：GPT、Claude、DeepSeek，换模型不用重写应用。

张路宇是谁 人物

Dify 创始人 & CEO，1991 年生，12 岁做个人站长，初中学历、自学成才。做过测试工具「飞蛾」，被 CODING 收购后随其进入腾讯，带过上百万开发者的 DevOps 平台。2023 年 3 月再创业，第一天就定下三件事：开源、To B、全球化。他招人「专挑大厂不要的人」，相信团队高于产品。

为什么值得读 时机

AI 应用正在从「聊天框里的演示」走向「真正运转的生产系统」，Dify 是这条路上跑得最快的开源项目：GitHub 星标全站第 51，装机 140 万台、覆盖 175 个国家，2026 年 3 月完成 3000 万美元融资。这本册子收录的是一手材料——他怎么说、怎么写、怎么做。

这本册子怎么用 读法

三条路径：赶时间，沿「推荐阅读路线」读六篇必读；想通读，按时间河从 2024 顺流而下；做功课，用搜索和筛选按主题定位。遇到生词点正文里的虚线词，或翻到末尾「术语速查」。每篇的「展开全文编译」是完整中译本，「阅读原文」通向原始出处。

拓展阅读

Further Reading · 读完原典之后往这里走
01

Dify GitHub 仓库

github.com/langgenius/dify

代码、Star、Issue 与贡献者的第一现场。判断一个开源项目是否真有活力，看这里的提交频率和 Issue 响应速度，比看任何报道都准。

→ 02

Dify 官方文档

docs.dify.ai

从部署、快速上手到 API 参考的完整文档。配合卷肆的官方页面一起读，半小时即可搭建第一个应用。

→ 03

Dify 官方博客

dify.ai/blog

产品发布、研究长文与公司公告的统一出口。张路宇的署名文章都在这里首发，订阅它等于订阅他的思考。

→ 04

Anthropic：Building Effective Agents

anthropic.com/engineering

Agent 领域被引用最多的设计共识：何时该用 Workflow、何时该用 Agent、编排的五种模式。读它再回头读张路宇的竞品点评，会更有味道。

→ 05

OpenAI：A Practical Guide to Building Agents（PDF）

cdn.openai.com

34 页免费指南：什么是 Agent、何时该建、如何设计护栏与人工介入。与 Dify 的「Agent + Workflow」思路对照阅读。

→ 06

AGENTS.md 官方站

agents.md

《分与合》里那份「写给 AI 的项目说明书」的行业标准形态，已被 6 万多个开源项目采用，由 Linux 基金会旗下机构看护。

→ 07

Model Context Protocol（MCP）

modelcontextprotocol.io

让 AI 应用以统一方式连接外部工具与数据的开放协议，相当于 AI 世界的 USB-C 接口。Dify 的 Agent 可以直接接入 MCP server。

→ 08

《Designing Data-Intensive Applications》

dataintensive.net

张路宇在「状态基础设施」长文中引用的分布式系统经典，Martin Kleppmann 著。想真正读懂那篇论文式长文，这是最好的梯子。
